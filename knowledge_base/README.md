# Knowledge Base — Standards & RFC Reference Store

This directory stores authoritative security standards, RFC specifications, and guidance documents for the **SentraIPS** RAG (Retrieval-Augmented Generation) engine (Phase 5).

## Structure

```
knowledge_base/
├── nist/
│   └── (NIST SP 800-77 Rev. 1, SP 800-52, etc.)
├── rfc/
│   └── (RFC 7296 - IKEv2, RFC 4301 - IPsec Architecture, RFC 8221 - ESP Crypto, RFC 9395, etc.)
└── README.md
```

## Objective in Phase 5

In Phase 5, deterministic security findings will be augmented with traceable, auditable citations directly mapped to relevant sections of these standards without hallucination or fabrication.
