# Frontend UI Dashboard

This directory will host the web-based interactive security dashboard (e.g., React or Next.js / Streamlit) in Phase 2+.

## Phase Roadmap
- **Phase 1**: Command-line orchestration, reproducible testbed, PCAP capture, and ground truth generation.
- **Phase 2+**: Visual dashboard displaying live IPsec status, cryptographic posture, captured PCAP flows, and vulnerability findings.
